# F 方式のデータ形式

GBA の 4bpp タイルシート（8x8 タイル = 32 バイトの並び）を縮めるための形式です。リファレンスの実装は `tools/fcomp.py`（圧縮と `decode()`）と `src/fcomp.c`（C の展開器）で、2 つは同じ手順です。

## 全体の考え方

1. **タイルの使い回し**: シートの中で同じ 32 バイトのタイルを 1 つにまとめ、「使うタイルの並び」と「元の位置ごとのタイル番号の並び」に分けます（番号は、使うタイルが 256 個以下なら 1 バイト、超えたら 2 バイト）。
2. **LZ77 + ハフマン**: 上の 2 つをつなげた列（これを *body* と呼ぶ）を、Deflate（RFC 1951）と同じ長さ・距離の区切りで LZ77 にし、ハフマン符号にします。
3. **共通辞書**: 多くのシートに出てくるタイル（最大 1024 個 = 32KB）を ROM に 1 つだけ置き、LZ77 の窓の「手前」として使います。窓は「共通辞書 + いま展開した分」で、距離は 65536 まで（Deflate の 32768 を 2 区切り増やしている）。
4. **ハフマンの表は全シートで 1 組**: シートごとには持ちません（記号 0〜285 の長さの表と、距離の表）。表は圧縮するシートの集合の統計から作ります。

## 1 シートのデータ（4 バイトそろえ）

| オフセット | 大きさ | 内容 |
|---|---|---|
| 0 | u16 | タイルの数（展開後の全タイル = 生の大きさ / 32） |
| 2 | u16 | 使うタイルの数 U |
| 4 | u8 | 番号の幅（1 か 2） |
| 5 | u8 | 0（予約） |
| 6 | u16 | ビット列の語（32 ビット）の数 |
| 8 | ... | ビット列（語数 x 4 バイト） |

ビット列は**下位ビットから**詰めます（最初のビットが 1 バイト目の bit0）。ハフマン符号は正準符号で、符号は上位ビットから順に読む並びを、ビット列には反転して書きます（Deflate と同じ）。

展開すると body（`U x 32` バイトの使うタイル + タイルの数 x 番号の幅 バイトの番号）になります。生のシートは、番号の並びの順に使うタイルを並べ直したものです。`FCompInflate`（C）が返すのは body までで、並べ直しは呼び出し側の仕事です（`examples/f_try_decode.c`、Python では `decode()`）。

## 記号

- 0〜255: 1 バイトのリテラル
- 256: 終わり
- 257〜285: 一致の長さ（Deflate と同じ区切り: 3〜258、追加ビットあり）。続けて距離の記号（0〜31）と追加ビット
- 距離の区切りは `DIST_BASE` / `DIST_EXTRA`（`tools/fcomp.py`）。Deflate の 30 個に 2 個足して 65536 までにしてあります

## 辞書との関係

距離が「いま展開した分」より遠いとき、足りないぶんは辞書の**後ろ**から読みます。
つまり仮想の窓は `辞書 + 展開済みの出力` で、距離 d は「現在位置から d バイト戻る」です。

## 表（C の展開器が読む形）

`struct FCompSet`（`src/fcomp.h`）に次を渡します。`tools/fcomp_cli.py pack` が `tables.s` として書き出します。

| 項目 | 内容 |
|---|---|
| `dict`, `dictSize` | 共通辞書とそのバイト数 |
| `litTable`, `litSymbols`, `litFast` | リテラル/長さの表。`BwFTable` = 長さ n の最初の符号・符号の数・最初の記号の番号（各 u16 x 16）。`litSymbols` = 符号の長さ順の記号。`litFast` = 先の 10 ビットで引く表（値 = 記号 \| 長さ << 9、0 なら 10 ビットより長い符号 = 1 ビットずつの遅い道） |
| `distTable`, `distSymbols`, `distFast` | 距離の表。`distFast` は先の 8 ビット |

## 展開器の約束

- 書き換え可能な static を使いません（状態は関数内の変数のみ）。
- 入力の範囲外は読みません（頭の語数の先は 0 とみなし、出力は `outSize` を超える書き込みを拒否）。壊れたデータは FALSE を返します。
- 呼び出し側は、出力の大きさ（body の大きさ = `U x 32 + タイルの数 x 幅`）を正確に渡します。ちょうど `outSize` バイトで終わったときだけ TRUE です。
